# Barcode Scanner by Camera

Scan barcodes using phone camera in Sale and Purchase orders for Odoo 18.

## Features

- Scan barcodes using device camera
- Add products to sale order by scanning
- Add products to purchase order by scanning
- Barcode scan history log
- Works on mobile and desktop

## Installation

1. Upload this module to your Odoo addons folder
2. Update apps list
3. Install "Barcode Scanner by Camera"

## Usage

- Open Sale Order or Purchase Order
- Click "Scan Barcode" button
- Enter barcode or scan using camera
- Product will be added to order
