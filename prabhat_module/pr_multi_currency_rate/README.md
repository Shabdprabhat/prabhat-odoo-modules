# Multi-Currency Live Rates

Auto-update currency exchange rates from live APIs for Odoo 18.

## Features

- Live exchange rate fetching
- Support for multiple APIs (Frankfurter, ExchangeRate-API, Fixer.io, OpenExchangeRates)
- Auto-update currency rates daily/hourly
- Manual refresh option
- Historical rate tracking

## Installation

1. Upload this module to your Odoo addons folder
2. Update apps list
3. Install "Multi-Currency Live Rates"
4. Configure rate provider

## Configuration

1. Go to: Accounting > Configuration > Currency Rate Providers
2. Add new provider
3. Select API service and enter API key
4. Set base currency and frequency
5. Click "Fetch Rates Now"

## Usage

- Rates are automatically fetched based on frequency
- Manually click "Fetch Rates Now" to update
- View rates in: Settings > Currencies
