# India GST & E-Way Bill Module

Indian GST compliance and E-Way Bill generation for Odoo 18.

## Features

- GSTIN validation for partners
- HSN Code management
- GST tax breakdown (CGST, SGST, IGST, Cess)
- E-Way Bill generation for invoices
- Vehicle number and transporter details
- Auto-calculation of GST amounts

## Installation

1. Upload this module to your Odoo addons folder
2. Update apps list
3. Install "India GST & E-Way Bill"
4. Configure GST settings

## Configuration

1. Go to: Accounting > Configuration > GST Settings
2. Set your company GSTIN and state
3. Create HSN codes for products
4. Add GSTIN to customers/vendors

## Usage

- Add GSTIN to partner form
- Add HSN code to products
- On invoice, view GST breakdown
- Click "Generate E-Way Bill" button
