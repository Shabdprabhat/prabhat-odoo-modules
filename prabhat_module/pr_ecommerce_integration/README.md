# E-commerce Integration

Connect Odoo with Shopify, WooCommerce, and Amazon for Odoo 18.

## Features

- Shopify integration
- WooCommerce integration
- Amazon Seller Central integration
- Sync products from e-commerce to Odoo
- Sync orders from e-commerce to Odoo
- Sync inventory levels
- Order status sync
- Auto-create customers

## Installation

1. Upload this module to your Odoo addons folder
2. Update apps list
3. Install "E-commerce Integration"
4. Configure your e-commerce platform

## Configuration

1. Go to: Sales > E-commerce Integration
2. Add new configuration
3. Enter API credentials
4. Set warehouse and pricelist

## Usage

- Configure platform connection
- Test connection
- Sync products, orders, and inventory
