# AI Document OCR

Extract text from images and PDF documents using AI/OCR for Odoo 18.

## Features

- Upload images and PDF documents
- Extract text using OCR (Tesseract, Google Cloud, AWS, Azure)
- Auto-create contacts from business cards
- Auto-create products from documents
- Support for multiple languages
- Document history and tracking

## Installation

1. Upload this module to your Odoo addons folder
2. Update apps list
3. Install "AI Document OCR"
4. Configure OCR settings

## Configuration

1. Go to: Documents > OCR Settings
2. Select OCR engine
3. Set API keys if using cloud OCR
4. Enable auto-create options

## Usage

- Go to: Documents > OCR Documents
- Click "Scan Document" to upload
- Process OCR to extract text
