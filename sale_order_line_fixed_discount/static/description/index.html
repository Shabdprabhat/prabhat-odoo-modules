Sale Order Line Fixed Discount

Apply exact currency discounts on sale order lines — no percentage calculation needed.

Odoo 18 Sales & Invoicing Free

What This Module Does

Odoo only allows percentage-based discounts on sale order lines by default. This module adds a Fixed Discount Amount field — enter the exact discount in your currency (e.g. ₹500 or $20) and the percentage is calculated automatically. Works on both Sale Orders and Invoices.

Key Features

💲
Fixed Amount Discount Field

⚡
Auto Percentage Calculation
The standard discount % field updates automatically — no manual calculation needed.
📋
Invoice Integration

🔧
Zero Configuration
Install and start using immediately. No settings, no extra modules required.

How It Works

1
Install the module
Search "Fixed Discount" in the Odoo Apps menu and install.
2
Open any Sale Order
You will see the new "Discount Amount" column on the order lines.
3
Enter the discount amount
Type the amount (e.g. 500). The discount % calculates automatically.
4
Confirm & Invoice
Confirm the order and create an invoice — discount flows over automatically.
