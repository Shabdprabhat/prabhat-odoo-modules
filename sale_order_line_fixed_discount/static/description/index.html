Sale Order Line Fixed Discount

Apply fixed currency amount discounts directly on sale order lines with instant calculations

Odoo 18 Sales & Invoicing Free App

Overview

By default, Odoo only allows percentage-based discounts on sale order lines. This module adds a Fixed Discount Amount field — so you can type in an exact currency amount (e.g. ₹500 off or $20 off) and Odoo automatically handles the rest. Works on both Sale Orders and Invoices.
