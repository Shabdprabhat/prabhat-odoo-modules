Sale Order Line Fixed Discount

Give customers exact currency discounts on every order line — no more percentage guessing.

The Problem
Odoo only supports percentage discounts by default. You have to calculate the percentage yourself when a customer wants "₹500 off".
→
🎉
The Solution
This module adds a Fixed Discount Amount field. Type the exact amount — Odoo calculates the percentage automatically.

How It Works

Up and running in under a minute — literally 4 steps.

1
Install Module
Search "Fixed Discount" in the Apps menu and install it.
→
2
Open Sale Order
Navigate to any sale order — you'll see the new "Discount Amt" column.
→
3
Enter Amount
Type the discount in currency (e.g. 500). The % auto-fills instantly.
→
4
Confirm & Invoice
Confirm the order. Discount flows to the invoice automatically.
