What This Module Does

Odoo only supports percentage-based discounts on sale order lines by default. When a customer asks for "₹500 off" or "$20 off", you have to reverse-calculate the percentage yourself. This module adds a Fixed Discount Amount field directly on each order line — enter the exact currency amount, and Odoo calculates the discount % automatically. Works on both Sale Orders and Invoices.
